# Direção visual do portfólio Mari Mou

Antes de alterar a interface, leia os cinco arquivos em `direcionamentos para IA/`:

1. `01_BRAND_STYLE_GUIDE.md` — direção de arte observada no Figma.
2. `02_DESIGN_TOKENS.json` — valores observados e papéis semânticos propostos.
3. `03_WEB_DESIGN_SYSTEM.md` — inventário e recomendações para o website.
4. `04_AI_DESIGN_INSTRUCTIONS.md` — resumo portátil para IAs.
5. `05-AI-Guidelines.md` — escopo de edição e orientações para Figma Make.

Esses documentos são uma auditoria inicial de seis frames desktop do Figma `Site Mari Mou 2`, não um sistema de marca oficialmente aprovado. Diferencie observações de propostas e confirme no código e no site publicado qualquer comportamento que os arquivos ainda não validaram. Preserve o escopo de cada pedido da Mariana e priorize as instruções explícitas dela quando houver divergência.
